# MiniCRM Toolkit

Desktop application built with Python and CustomTkinter.

## Features

✅ Update webinar history
✅ Save ready-to-import MiniCRM Excel files

## Planned features

- Unique email extraction
- Duplicate removal
- Additional MiniCRM utilities

## Technologies

- Python
- CustomTkinter
- Pandas
- OpenPyXL

## Project structure

core/
modules/
ui/
output/

## How to run

pip install -r requirements.txt

python app.py
